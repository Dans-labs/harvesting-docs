# Solr

Apache Solr: <https://solr.apache.org/>

If you have access to the Solr interface and you have not harvested all metadata but just want to inspect some metadata quickly. 
Downside its that the result is flattened, so not structured as the JSON from the exports. You do get a bit more control, because you can use the full Solr API, there is no Dataverse in between.
